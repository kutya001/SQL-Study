# Уроки и задания для курса «SELECT с нуля»

Курс учит аналитиков читать данные в SQL Server: **только SELECT**, от первого запроса до оконных функций. Репозиторий: https://github.com/kutya001/SQL-Study. Ученики — аналитики, которые пришли из Excel: объясняй просто, на русском, с примерами из банка/торговли/производства.

## 0. Подготовка
- Получи код курса: `git clone https://github.com/kutya001/SQL-Study` (или архив). Дальше `КУРС` — корень.
- Определи, куда идёт контент:
  - **основной курс** (база Bank) — `content/modules/*.js`, `content/trainer.js`, `content/cheatsheet.js`. Формат — `docs/КОНТЕНТ.md` (прочитай целиком);
  - **мини-курс учебной базы** — `schemas/ИМЯ/course.json`, `tasks.json`, `trainer.json`, `examples.json`. Формат — `schemas/ФОРМАТ.md` (разделы 4–9).
- Посмотри 1–2 соседних модуля целиком, чтобы попасть в стиль и уровень сложности. Не повторяй уже существующие задачи.
- Таблицы базы смотри в схеме: для Bank — `js/engine/bankdb.js` или `node tools/sql.js bank "SELECT TOP 5 * FROM Clients"`; для учебных баз — `schemas/ИМЯ/schema.json`.

## 1. Структура урока
- Урок — 10–15 минут: 3–6 шагов `text`/`example`, 1–2 вопроса `quiz` (или `order`), затем мини-тренировка из 3–5 задач от простой к сложной.
- Один урок — одна идея. Сначала зачем (аналогия с Excel, бизнес-вопрос), потом синтаксис, потом типичные ошибки (`<div class="warn">`) и советы (`<div class="tip">`).
- Примеры (`example`) должны выполняться и давать понятный результат; в `after` — что заметить в результате и что попробовать изменить.
- Домашнее задание модуля — не меньше 3 задач, «из жизни»: формулировка как от руководителя («Отдел рисков просит…»).
- Интерактивные схемы (`widget`) — только из списка в `docs/КОНТЕНТ.md`.
- Ссылки «Почитать» (`read`) — на главы https://metanit.com/sql/sqlserver/. Тексты пиши сам, не копируй.

## 2. Задачи — правила
- **Сначала результат эталона:** `node tools/sql.js bank "запрос"` (или `ИМЯ` базы). Не пустой, числа разумные, без ничьих на границе `TOP`.
- **Однозначность.** `TOP` — только с `ORDER BY` и разбивкой ничьих. Периоды по datetime — `>= '20261001' AND < '20261101'`. Не завязывайся на `GETDATE()` в Bank (там текущая дата компьютера).
- **Типы и имена.** Суммы/доли — `CAST(… AS DECIMAL(p,s))` с типом в тексте; деление на `100.0`. «Назовите столбец X» → `check: { names: true }`.
- **Порядок.** Если в тексте сказано «отсортируйте» — `check.order` (номер столбца с 0) или `ordered: true`.
- **Типичные ошибки** — в `wrong` (например, `>=` вместо `>`, `COUNT(*)` вместо `COUNT(DISTINCT …)`, `INNER` вместо `LEFT JOIN`). Другие верные решения — в `alsoOk`.
- **Требования к способу решения** («решите через оконную функцию») — `check.require` / `check.forbid` с понятным сообщением.
- **id** — по схеме соседей (`m05l2t3`, `m05hw4`, `t3-12`, `s2-5`, `tr4-1`), уникальные и **неизменные**: к ним привязан прогресс учеников. Существующие id не переименовывай и не переиспользуй.
- Подсказка (`hint`) — направление, а не готовый ответ.
- Тренажёр: `level` 1–5 (Разминка, Базовый, Средний, Продвинутый, Эксперт) и `tags`.

## 3. Проверка (обязательно)

```bash
node tools/validate-course.js m05        # один модуль основного курса
node tools/validate-course.js            # весь основной курс, тренажёр и справочник
node tools/check-pack.js schemas/ИМЯ     # мини-курс учебной базы
```

Добейся 0 ошибок. Предупреждения разбери: «эталон возвращает 0 строк» почти всегда ошибка в задаче (или нужен `allowEmpty: true`).

Если менялись файлы в `schemas/` — пересобери сборку баз: `node tools/build-index.js`.

Новый модуль основного курса: файл `content/modules/mNN-tema.js` и его имя в `moduleFiles` в `content/course.js`. Новые достижения — в `achievements` там же.

## 4. Сдача
- В репозиторий: ветка, коммит, pull request с перечнем новых уроков/задач и результатом проверки. GitHub Actions повторит проверки.
- Без доступа к репозиторию: отдай изменённые файлы (или архив через Python `zipfile`) и напиши, куда их положить.
- В ответе коротко: что добавлено (модули/уроки/задачи по уровням), результат проверки, что посмотреть вручную в браузере.
