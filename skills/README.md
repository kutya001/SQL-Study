# Скиллы для ИИ-помощников

Каждая папка — скилл в формате Agent Skills (`SKILL.md` с описанием в шапке). Скилл подсказывает ИИ (Claude и другим ассистентам), как делать работу по правилам этого проекта и как проверить результат движком курса.

| Скилл | Когда использовать |
|---|---|
| [sql-kurs-uchebnaya-baza](sql-kurs-uchebnaya-baza/SKILL.md) | нужна новая учебная база: тематика → схема, данные, практикум, тренажёр, примеры, мини-курс |
| [sql-kurs-uroki](sql-kurs-uroki/SKILL.md) | нужны новые уроки, задачи, ДЗ, вопросы или задачи тренажёра |
| [sql-kurs-razrabotka](sql-kurs-razrabotka/SKILL.md) | нужно доработать само приложение: движок T-SQL, страницы, проверку, хранилище |

## Как подключить

- **Claude (claude.ai, приложение)** — заархивируйте папку скилла в zip и загрузите в разделе скиллов в настройках. Или просто приложите `SKILL.md` к сообщению.
- **Claude Code** — скопируйте папку скилла в `.claude/skills/` проекта или `~/.claude/skills/`.
- **Другие ассистенты** — дайте ссылку на `SKILL.md` или вставьте его текст в начало разговора.

Пример запроса: «Используй скилл sql-kurs-uchebnaya-baza. Тематика — автосалон».
