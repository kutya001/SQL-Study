# SQL-Study — курс «SELECT с нуля»

Интерактивный курс T-SQL (только SELECT) — одностраничное приложение на чистом JavaScript без сборки, зависимостей и сервера. Работает из папки (`file://`) и с GitHub Pages.

- Архитектура: `docs/АРХИТЕКТУРА.md`; разработка и проверки: `docs/РАЗРАБОТКА.md`.
- Контент основного курса: `docs/КОНТЕНТ.md`; формат учебных баз: `schemas/ФОРМАТ.md`.
- Скиллы проекта: `skills/` — `sql-kurs-uchebnaya-baza` (новая учебная база), `sql-kurs-uroki` (уроки и задачи), `sql-kurs-razrabotka` (доработка приложения). Перед такой работой прочитай соответствующий `SKILL.md`.

Правила:
- Никаких внешних библиотек, CDN и сетевых запросов; локальные файлы — только через `<script>` (иначе не работает `file://`).
- Интерфейс и тексты — на русском.
- id модулей, уроков, задач и баз не меняются — это ключи прогресса учеников.
- После правки `schemas/` — `node tools/build-index.js`.
- Перед коммитом: `node tools/validate-course.js && node tools/validate-packs.js` — 0 ошибок.
