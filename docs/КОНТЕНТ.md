# Как устроен контент основного курса

Основной курс (база **Bank**) — это JavaScript-файлы в папке `content/`. Они не содержат логики, только данные: тексты, примеры, задачи. Учебные базы из `schemas/` описываются отдельно, в JSON — см. [schemas/ФОРМАТ.md](../schemas/ФОРМАТ.md).

```
content/
  course.js          настройки курса, порядок модулей, уровни тренажёра, достижения
  modules/m01-….js   по файлу на модуль: уроки, мини-тренировки, домашнее задание
  trainer.js         задачи тренажёра (уровни 1–5)
  cheatsheet.js      справочник (каждый пример запускается)
```

После любой правки запустите проверку — она выполнит **все** примеры и эталоны:

```bash
node tools/validate-course.js        # весь курс
node tools/validate-course.js m03    # один модуль
```

## course.js

```js
window.COURSE = {
  title: 'SELECT с нуля',
  config: {
    lockModules: false,          // true — модуль открывается после уроков предыдущего
    solutionAfterTries: 3,       // после скольких неудачных проверок подсветить «Решение»
    xp: { quiz: 5, task: 10, hw: 25, lesson: 20, module: 100, trainer: [10, 15, 20, 30, 40] }
  },
  moduleFiles: ['m01-vvedenie.js', …],   // порядок подключения файлов из content/modules
  trainer: { levels: [ { name: 'Разминка', desc: '…' }, … ] },
  achievements: [ { id, icon, title, desc, test: function (s) { … } } ]
};
```

Новый модуль: создайте файл в `content/modules/` и впишите его имя в `moduleFiles`.

## Модуль

```js
COURSE.addModule({
  id: 'm03', num: 3,
  title: 'Фильтрация строк: WHERE',
  short: 'Одна строка для карточки модуля на главной.',
  goal: '<p>Зачем этот модуль — 2–3 предложения.</p>',
  read: [ ['Фильтрация. WHERE', 'https://metanit.com/sql/sqlserver/4.5.php'] ],  // «Почитать»
  lessons: [ /* уроки */ ],
  homework: [ /* задачи ДЗ (не меньше 3) */ ]
});
```

## Урок

```js
{
  id: 'm03l1', title: 'Условия сравнения', minutes: 12,
  steps: [ /* шаги урока по порядку */ ],
  training: [ /* мини-тренировка после урока: задачи и вопросы */ ]
}
```

### Шаги урока

| `t` | Поля | Что это |
|---|---|---|
| `text` | `title`, `html` | теория. В HTML можно: `<p>`, `<ul>`, `<table>`, `<code>`, `<pre class="sql">`, `<div class="tip"><b>Заголовок</b>текст</div>`, а также блоки `warn`, `note`, `key` |
| `example` | `title`, `sql`, `after` (HTML под примером), `autorun`, `noTrace` | запускаемый пример; ученик может менять запрос |
| `quiz` | `id`, `q`, `options[]`, `answer` (номер с 0 или массив номеров), `explain` | вопрос с вариантами |
| `order` | `id`, `q`, `items[]` (в правильном порядке), `explain` | расставить элементы по порядку |
| `widget` | `title`, `w`, `opts` | интерактивная схема. `w` — одно из: `joinViz`, `nullTruth`, `likeViz`, `setsViz`, `windowViz`, `dateDiffViz`, `betweenViz`, `groupViz`, `caseViz`, `execOrder`, `excelMap` |
| `task` | см. ниже | задача прямо в уроке |

## Задача

Задачи в `training`, `homework` и в тренажёре устроены одинаково.

```js
{
  t: 'task',                       // в training; в homework и trainer не нужен
  id: 'm03l1t2',                   // уникальный и НЕИЗМЕННЫЙ — к нему привязан прогресс
  title: 'Крупные остатки',
  text: '<p>Выведите номер счёта, валюту и остаток счетов с остатком <b>больше 250 000</b>.</p>',
  solution: 'SELECT AccountNumber, Currency, Balance\nFROM Accounts\nWHERE Balance > 250000;',
  hint: 'Подсказка (необязательно)',
  starter: 'SELECT …',             // текст в редакторе при открытии (необязательно)
  check: {                         // как сравнивать (необязательно)
    names: true,                   // имена столбцов должны совпасть (если в тексте «назовите столбец …»)
    order: [[2, 'desc']],          // порядок строк: [номер столбца с 0, 'asc'|'desc'], …
    ordered: true,                 // строгий порядок строк, как у эталона
    require: [['\\bJOIN\\b', 'Решите задачу через JOIN']],   // регулярное выражение, которое должно быть в коде
    forbid:  [['\\bTOP\\b', 'Здесь нельзя TOP']]             // …которого не должно быть
  },
  wrong:  ['SELECT … типичная ошибка …'],   // проверка убедится, что это НЕ засчитывается
  alsoOk: ['SELECT … другое верное решение'], // …а это засчитывается
  allowEmpty: true                 // эталон может вернуть 0 строк (иначе — предупреждение)
}
```

Проверка сравнивает **результат** запроса ученика с результатом эталона: столбцы, строки (как мультимножества), при `order`/`ordered` — порядок, при `names` — имена столбцов. Текст запроса не важен, если нет `require`/`forbid`.

В тренажёре у задачи ещё есть `level` (1–5) и `tags: ['JOIN', 'GROUP BY']`.

## Правила хороших задач

- **Однозначный эталон.** Если есть `TOP`, нужен `ORDER BY` с разбивкой ничьих, и на границе не должно быть ничьих. Периоды по `datetime` — диапазоном: `>= '20261001' AND < '20261101'`.
- **Типы в тексте.** Суммы и доли — `CAST(… AS DECIMAL(p,s))`, и тип назван в тексте задачи. Деление на `100.0`, а не на `100`.
- **Имена столбцов.** Если в тексте сказано «назовите столбец», ставьте `check: { names: true }`.
- **Типичная ошибка — в `wrong`.** Например, `>=` вместо `>` или `COUNT(*)` вместо `COUNT(DISTINCT …)`: проверка подтвердит, что такой ответ не принимается.
- **Посмотрите результат эталона** перед публикацией: `node tools/sql.js bank "…"`. Не пустой, числа разумные.
- **id не меняются.** Новые задачи получают новые id; старые не переименовываются и не переиспользуются.

## Справочник (cheatsheet.js)

```js
window.CHEAT = [
  { title: 'Основы SELECT', items: [
    { h: 'Заголовок примера', sql: 'SELECT …', note: 'пояснение (необязательно)', noRun: true /* не выполнять при проверке */ }
  ] }
];
```

## Встроенная база Bank

Таблицы и данные генерируются кодом в `js/engine/bankdb.js` (детерминированно — у всех учеников одинаковые данные). Таблицы: `Branches`, `Clients`, `Accounts`, `Transactions`, `LoanProducts`, `Loans`, `Employees`, `CurrencyRates`, `ImportRaw`. `GETDATE()` в этой базе возвращает текущие дату и время компьютера, поэтому в задачах про «сегодня» эталон и ученик получают одинаковый результат, но сам результат меняется со временем — для однозначных задач используйте фиксированные даты.

Если меняете генератор, все эталоны курса могут дать другие числа — обязательно прогоните `node tools/validate-course.js` и проверьте тексты задач, где упоминаются конкретные значения.
